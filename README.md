# Abyssal-Gears-Deep-Sea-Defense
Abyssal Gears is an arcade-style 2D side-scrolling shooter set in a murky alien abyss inhabited by hostile bio-mechanical creatures. Developed using pure HTML5 Canvas, CSS3, and Object-Oriented JavaScript, players command an upgraded sub-aquatic craft to battle hive swarms, dodge hazards, and accumulate high scores before time runs out.
